# assets-src

Исходники рисованного арта (до сборки в атласы). Структуру, размеры, названия файлов и чек-лист приёмки
см. в [`docs/design/art-brief.md`](../docs/design/art-brief.md), разделы 3, 6 и 7.

- Кладите сюда PNG строго по структуре из брифа.
- Для каждого файла добавляйте запись в `SOURCE.md` (инструмент, дата, что правилось вручную).
- Сборка в атласы и конфиги — задача `tools/` (появится вместе с загрузчиком ассетов, Фаза V1).
- Большие исходники (psd/kra/aseprite) храните вне репозитория или в Git LFS.
