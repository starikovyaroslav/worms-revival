# Roadmap

Живой документ: единственный источник правды о том, что сделано и что дальше.
**Правило:** закончил задачу — поставь `[x]` и обнови «Текущий фокус» в том же коммите.

Легенда: `[x]` готово · `[~]` частично · `[ ]` не начато · 🎨 нужен арт · 🔊 нужен звук

## Как продолжить работу в новой сессии

1. Прочитай этот файл, затем `docs/design/architecture.md` и `docs/design/gdd.md`.
2. `npm install && npm run check` — typecheck + lint + тесты должны быть зелёными.
3. `npm run dev` → http://localhost:5173 (меню). `?seed=1&cpu=3` пропускает меню и запускает бой ботов.
4. Проверка детерминизма в 4 движках: `npm run test:determinism`.
5. Скриншоты для проверки визуала: `node tools/shot.mjs <url> <out.png> "<действия>" <ждать_мс>`
   (см. шапку файла; `e:<js>` выполняет выражение в странице, `window.__game` — отладочный хук).
6. Коммиты маленькие, Conventional Commits (`feat(sim):`, `fix(render):`, …).

## Принципы (не нарушать)

- **Детерминизм.** `packages/sim` и `packages/mapgen` не используют `Math.sin/cos/random`, `Date`, DOM
  (линтер это запрещает). Любая случайность — через `world.rng`. Всё, что влияет на исход, обязано
  попадать в `hashInto`.
- **Рендер никогда не влияет на симуляцию.** Частицы, свет, шейдеры, тряска — только презентация,
  питаются событиями `world.drainEvents()`.
- **Оружие — данные + небольшой код** в `packages/sim/src/weapons/defs/*`, числа — в `content`.
- **Реплей = конфиг матча + лог команд.** Любое изменение логики ломает старые реплеи
  (поднимай `REPLAY_VERSION`).

## Карта репозитория

| Путь               | Что там                                                                   |
| ------------------ | ------------------------------------------------------------------------- |
| `packages/sim`     | Детерминированная логика: мир, червяки, оружие, ходы, правила             |
| `packages/mapgen`  | Генерация карт по seed, поиск мест для червяков                           |
| `packages/content` | Схемы, Wormpot, команды, фразы, названия оружия, реплеи, `buildGameSetup` |
| `packages/render`  | PixiJS: земля, червяки, сущности, камера, вода, частицы                   |
| `packages/ai`      | Бот: перебор выстрелов в копии мира                                       |
| `apps/client`      | Vite + Preact: меню, HUD, панель оружия, звук, цикл игры                  |
| `tools`            | Скриншоты, проверка детерминизма                                          |
| `docs`             | Лор (`docs/lore`), дизайн, этот роадмап                                   |

## Текущий фокус

**Фаза V — «Дорогой» визуал и отклик (Visual & Feel overhaul).** Готовы V3a (постобработка), V3b (свет), V4a (взрывы) и часть V4 (juice). Дальше: V3c шейдер земли и воды → V1 инфраструктура ассетов → V2 персонажи (арт) → V5 UI.
Первая версия графики была процедурной (векторные примитивы Pixi) и выглядит слабо.
Решение: перейти на спрайты и анимации из конфигов, освещение, шейдеры, «сок».
Детали и решения — в `docs/design/visual-direction.md` (создаётся по итогам исследования).
