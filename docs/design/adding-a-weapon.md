# Как добавить оружие

Одно оружие = одна запись `WeaponSpec` в `packages/content/src/weapons/*.ts` плюс строка в схеме.
Типы лежат в `packages/sim/src/weapons/spec.ts`, данные в `content`, в игру они попадают через
`Ruleset` (`GameSetup.rules`, его собирает `buildGameSetup`). `sim` не импортирует `content`.

## Запись

```ts
{
  id: 'bazooka',
  sim: { archetype: 'launcher', aim: 'angle', charge: true, speed: 14,
         projectile: { look: 'missile', radius: 2, wind: 1, impact: 'explode', blast: { damage: 50 } } },
  ui: { name: 'Базука', hint: '...', icon: '🚀', row: 1, col: 0 },   // панель: F-ряд и колонка
  ai: { usable: true, rank: 0 },                                      // порядок предпочтения бота
  view: { look: 'missile', sound: 'launch' },                         // вид и звук выстрела
  listing: 'unlisted',                                                // только если нет в схемах
}
```

- `sim` - флаги (`aim`, `charge`, `fuse`, `bounce`, `shots`, `retreat`, `endsTurn`, `needsSky`,
  `airborne`, `oncePerTurn`, `action`...) и архетип с числами:

| archetype  | что делает                                                        | примеры                          |
| ---------- | ----------------------------------------------------------------- | -------------------------------- |
| `launcher` | снаряд из дула по линии прицела (кластеры, фитиль, отскок)        | базука, граната, банан, ваза     |
| `placed`   | кладёт снаряд или мину под ноги                                   | динамит, мина                    |
| `animal`   | выпускает ходячую бомбу (или несколько, или стреляет ею)          | овца, коровы, овцемёт            |
| `airRaid`  | самолёт сбрасывает N зарядов (снаряд, мина, животное)             | авиаудар, ковёр, налёт мин       |
| `burst`    | очередь, которую игрок ведёт прицелом                             | узи, миниган, пистолет           |
| `hitscan`  | мгновенный выстрел (вторая трубка по улучшению)                   | дробовик                         |
| `melee`    | удар по червякам перед собой, отброс, пробитие земли              | бита, огненный удар, тычок       |
| `tool`     | инструмент, которым игрок управляет после выстрела                | верёвка, ранец, лампа, парашют   |
| `utility`  | включает флаг на ход                                              | низкая гравитация, двойной урон  |
| `action`   | управление ходом, делает сама игра                                | пропуск, сдаться                 |
| `custom`   | своё поведение по имени (`behaviour`) + `params`                  | миномёт, ракета-самонаводка, нюк |
| `inline`   | код прямо в спеке; только для тестов и прототипов (не хешируется) | тестовое оружие в `sim/test`     |

- `ui.row/col` - клетка панели (0 = утилиты, 1..12 = F1..F12); коллизии ловит тест реестра.
  Порядок в `Ruleset` (его же видят бот, ввод и выбор оружия по умолчанию) = порядок ряд/колонка.
- `view.look` - id вида из типа `Look` (снаряды) или `AnimalLook`. Отрисовка и арт в `render`.
  Свет и след снаряда задаются по виду в `packages/content/src/weapons/looks.ts`.
- `view.sound` - `SoundId`, его играет архетип при выстреле.

## Шаги

1. Запись в подходящий файл `content/src/weapons/` (или новый, подключить в `weapons/index.ts`).
2. Строка в нужных схемах `packages/content/src/schemes.ts` (иначе `listing: 'unlisted'`).
3. Иконка (опционально, иначе эмодзи из `ui.icon`): `apps/client/public/assets/weapons/icon/<id>.png` (и запись в манифесте ассетов).
4. Если нужен новый внешний вид: добавить значение в `Look` (`sim/.../spec.ts`), строку в `PROJECTILE_LOOKS` (`RENDERED_LOOKS` строится из неё)
   в `render/src/views/projectile.ts` (имя ассета или функция рисования); компилятор не даст забыть.
5. Если нужны новые звук - `SoundId` и синтезатор в `apps/client/src/audio/sounds.ts` (тип `Record<SoundId, ...>`).
6. Если ни один архетип не подходит: поведение со своим кодом в `sim/src/weapons/behaviours/`
   (`Behaviour<Params>`), имя и тип параметров в `behaviours/index.ts`, в данных `archetype: 'custom'`.
   Новая сущность (класс в `sim/src/weapons`) должна писать всё, что влияет на исход, в `hashInto`.
7. `npm run check`. Тест реестра (`content/test/registry.test.ts`, `apps/client/test/registry.test.ts`) проверяет:
   уникальные id и клетки панели, русское имя/подсказка/иконку, место в схеме или `unlisted`,
   ранг бота, что `look` умеет рисовать рендер и что для `sound` есть синтезатор.
   Золотой реплей: схема `arsenal` включает всё оружие, а сценарий матча перебирает его, поэтому новое
   оружие меняет реплей: перезапиши (`UPDATE_GOLDEN=1`, см. `ai/test/golden.test.ts`) и подними
   `REPLAY_VERSION`. Так же при изменении чисел существующего оружия.

Пример: `packages/content/test/rules/newWeapon.test.ts` добавляет `launcher`-оружие одной записью и стреляет им.

## Что в хеше правил

`rulesetHash()` покрывает схемы и флаги каждого оружия. Числа `params` и код в него не входят
(их проверяет золотой реплей); сменил число баланса - перезапиши реплей и подними `REPLAY_VERSION`.
