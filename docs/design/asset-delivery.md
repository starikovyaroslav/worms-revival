## Цвет, прозрачность и размер

- DB32 остаётся ориентиром художественного стиля, **не ограничением количества цветов PNG**.
  Экспорт не вызывает `reduce`/`snap` и не порогует исходную альфу.
- PNG — lossless RGBA. Цвета и промежуточная прозрачность сохраняются при нарезке/масштабировании;
  композиция слоёв и заделка швов используют альфа-смешивание.
- У старых фоновых/предметных мастеров розовый chroma-key удаляется вместе с явно розовой каймой.
  Если оригинал не имел полупрозрачности, экспорт её искусственно не создаёт.
- Иконки: 6× (обычно 84×84); персонаж и остальные спрайты: не менее 4×;
  фоны, логотипы и военная авиация: 3×. Самая длинная сторона каждого PNG — минимум 64 px.
- `w/h` манифеста — размер в мире; `pixelW/pixelH` — размер PNG. Физика, коллизии и масштаб
  предметов не увеличены. Повороты, смена кадров, стороны, могилы, ранец и значки учитывают плотность.
- Земля отрисовывается с повышенной плотностью (до 3×, с ограничением памяти), коллизии остаются
  на прежней сетке. Период тайлов и параллакс заданы логическими размерами.

## Честные границы готового набора

Это готовый набор для текущих механик, не обещание отдельной ручной анимации на каждое оружие.
81 кадр прицеливания, часть 56 кадров действий, парашюты и вращения составлены из новых мастеров
детерминированными преобразованиями. Короткие циклы существ сохранены; взрывы используют семейства
с разными слоями и параметрами. Вода, верёвка, свет, искры, экранные вспышки и двоение — кодовые эффекты.
Слепота/галлюцинации не вводятся как новые игровые статусы. Музыка и отдельный новый набор декора
не входят в этот проход. Дополнительных генераций для работы текущих механик не требуется.

## Воспроизведение

```sh
npm run art:desktop
npm run art:review
npm run art:test
npm run check
npm run build
npm run test:determinism
```

Node 22.18+ и ImageMagick 7. Мастера сохраняются локально в игнорируемой `assets-in/`;
готовые PNG, манифесты и отчёты находятся в Git и не требуют генерации при сборке игры.
Без локальных мастеров повторный экспорт недоступен; обычные сборка и тесты используют готовые PNG.
Новые листы: `assets-in/desktop/*.png`; старые окружение/VFX/авиация — в прежних подпапках.
Подробные промпты новых листов: `tools/art/desktop-prompts.mjs`, порядок ячеек:
`legacy-hd-sources.json` / `arsenal-sources.json`. Генератор — встроенный imagegen.
Исходные результаты новой генерации также сохранены в
`/home/yaroslav/.codex/generated_images/01a15cdb-bc50-7350-9ea2-a30111bf6e3f/`.
Старые quantized CLI заблокированы, чтобы случайно не перезаписать готовую графику.

Браузерные проверки против запущенного клиента:

```sh
node tools/art/integration-check.mjs
node tools/art/desktop-check.mjs
node tools/art/arsenal-check.mjs
node tools/art/vfx-check.mjs
```

Покрыты четыре темы, меню на нескольких разрешениях, параллакс, кратеры, существа/предметы,
Full HD / 1440p / DPR 2, ракеты и самолёты, эффекты и звук, CRT, отсутствие необязательных пакетов,
уменьшение анимации и неизменность симуляции. Скриншоты: `assets-in/previews/`.
Проверки цвета/альфы и физического размера PNG защищают от возврата прежней обработки.

Итог проверки: 320 тестов проекта, 20 арт-тестов, сборка и четыре браузерных сценария проходят.
Все 696 уникальных текстур загружены в браузере; у 698 PNG нет расхождений манифеста,
низкоплотных остатков или незарегистрированных файлов. Хеш симуляции во всех четырёх движках:
`114089616`. Сборка сохраняет прежнее предупреждение Vite о JS-чанке более 500 kB;
к графическим файлам и их качеству оно не относится.
