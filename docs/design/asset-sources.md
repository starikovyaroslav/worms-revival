# Источники ассетов и лицензии

Дата исследования: 2026-10-08. **Всегда перепроверять лицензию конкретного пакета перед использованием**
и записывать использованное в `ATTRIBUTIONS.md` (файл, источник, лицензия, ссылка).

## Честная оценка

Готовых паков, которые дадут **цельный «дорогой» набор** (червяк с мимикой, оружие, UI, эффекты, фоны
в одном стиле), не существует: стиль Worms уникален, а общедоступные паки разношёрстны. Реалистичные пути:

| Путь                                                                                       | Плюсы                                    | Минусы                                                                                                          |
| ------------------------------------------------------------------------------------------ | ---------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **A. Художник (фриланс/студия)**                                                           | Единый стиль, уникальность, чистое право | Бюджет и сроки; нужна постановка ТЗ                                                                             |
| **B. Гибрид: платные/CC0 паки для FX и UI + заказ ключевого арта (червяк, лицо, логотип)** | Лучшее соотношение цены и качества       | Нужна «сшивка» стиля (палитра, обводка, цветокор)                                                               |
| **C. ИИ-генерация + ручная доработка**                                                     | Быстро, дёшево для концептов и текстур   | Авторское право: чисто ИИ-работы не охраняются; стилевая согласованность хуже; требуется человеческая доработка |
| **D. Только процедурка/CC0**                                                               | Бесплатно, чисто                         | Именно это сейчас и выглядит слабо                                                                              |

**Рекомендация: путь B.** Что берём готовым, что заказываем:

| Категория                            | Источник                                          | Примечание                                          |
| ------------------------------------ | ------------------------------------------------- | --------------------------------------------------- |
| Взрывы, дым, огонь, вспышки (атласы) | CC0: Kenney, OpenGameArt; платные паки на itch.io | Подтянуть цветокоррекцией под палитру игры          |
| Иконки UI, рамки, кнопки             | Kenney UI (CC0) как основа или заказ              | Единый штрих критичен — лучше заказать набор оружия |
| Червяк (текстура кожи, лицо, руки)   | **Заказ / ИИ+доработка**                          | Ключевой «брендовый» актив                          |
| Оружие в руках, снаряды, ящики       | **Заказ** (или адаптация паков)                   | 30–60 штук, в едином стиле                          |
| Фоны, параллакс, объекты на земле    | Заказ + процедурное дополнение                    | По теме: луг, пустыня, арктика, ад, …               |
| Шрифты                               | SIL OFL (Google Fonts) с кириллицей               | См. `ui-review.md`                                  |

## Правила работы с ассетами

1. Каждый внешний ассет → запись в `ATTRIBUTIONS.md` в тот же коммит.
2. ИИ-сгенерированное не используем «как есть» для персонажей/логотипа: только как референс или с
   существенной человеческой доработкой; раскрываем при публикации, где требуется.
3. Никаких ассетов Team17, Hedgewars, Warmux. Оригинальное название и дизайн персонажа.
4. Исходники (psd/aseprite/blend) храним отдельно от собранных атласов (`assets-src/` → `assets/`).

## Фоны, земля и сцены: где брать (обновление 2026-10-09)

В листе GBA с The Spriters Resource есть только персонажи, оружие, ящики и эффекты. Фонов и текстур земли
там нет. Варианты:

| Путь                                                  | Что получаем                                                                                                                                                                                                                                                                                                                                                 | Условия                                                                                                                                                                                                                                 |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Оригинальные ландшафты W:A (личное использование)** | Настоящие фоны, текстуры земли, травы, объекты тем из Worms Armageddon. Они лежат в `Level.dir` каждой темы (`.IMG` — картинки, `.SPR`+`.SPD` — анимации). Сообщество извлекает их утилитой WA Directory Editor / Sprite Editor (см. [Terrain Creation Guide](https://worms2d.info/Terrain_Creation_Guide)). Работает только с вашей собственной копией игры | Чужое авторское право (Team17): только для личного использования, класть в `apps/client/personal/`, не публиковать. Сайт The Spriters Resource по Worms Armageddon PC рипов земли в поиске я не нашёл: проверьте поиском на самом сайте |
| **CC0 / свободные паки**                              | Параллакс-фоны и тайлы платформеров. Кандидаты на OpenGameArt: [free vector grass tileset](https://opengameart.org/content/free-vector-grass-tileset) (CC0, 5 слоёв параллакса), [Fantasy World Game Background](https://opengameart.org/content/parallax-backgrounds) и др.                                                                                 | Лицензию каждого пака проверять на странице: есть расхождения между метками и текстом автора; CC-BY требует указания автора (см. `ATTRIBUTIONS.md`)                                                                                     |
| **Процедурно (сейчас)**                               | Небо полосами, холмы, земля с дизерингом — всё из кода, без внешних файлов                                                                                                                                                                                                                                                                                   | Чисто, но проще по виду                                                                                                                                                                                                                 |
| **ИИ-лист фонов**                                     | Полосы на тему по промпту из `docs/design/art-sheets.md` (будет добавлено)                                                                                                                                                                                                                                                                                   | Правила про ИИ-арт см. в брифе                                                                                                                                                                                                          |

Рекомендация для личного прототипа: взять фоны и текстуры земли из **своей копии W:A** (первый путь),
для публичной версии: CC0-паки + собственные ландшафты.
