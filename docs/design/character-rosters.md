# Составы классов — 2026-10-22

В каждом классе — четыре самостоятельных взрослых персонажа. Это стандартная команда
из четырёх без повторов: разные лица, одежда и темперамент, а не перекраска.
В большем составе назначение повторяется с пятого; вручную можно повторять любого.
Классы косметические: одинаковые коллизии, здоровье, скорость и правила оружия.

| Класс        | Четыре участника                                                                   |
| ------------ | ---------------------------------------------------------------------------------- |
| Брутальные   | Брутальный; Брутальная коммандо; Брутальный сапёр; Брутальная громила              |
| Мягкотелые   | Мягкотелый; Мягкотелая героиня; Добродушный повар; Мечтательная художница          |
| Гламурные    | Гламурная дива; Гламурный красавчик; Гламурный рокер; Кабаретная дива              |
| Доминатрикс  | Чёрная командирша; Ледяная инспекторша; Рыжая надзирательница; Железная начальница |
| Пожилые      | Старый ворчун; Старая ворчунья; Старый капитан; Старая профессорша                 |
| Больные      | Больной; Больная героиня; Простуженный клерк; Усталая санитарка                    |
| Ветераны     | Потрёпанный ветеран; Потрёпанная ветеранка; Ветеран-моряк; Ветеранка-лётчица       |
| Классические | Классический нахал; Классическая нахалка; Нахальный панк; Нахальная разведчица     |

32 игровых образа × 16 поз = 512 рисованных кадров. У каждого есть ожидание и моргание,
четыре фазы ходьбы, прыжок/падение/приземление, боль, прицеливание, бросок, удар,
верёвка, поражение и победа. Для каждой семьи используется свой профиль пластики.

В классе «Доминатрикс» поставляются только закрытые неэротические боевые наряды.
Исходный отклонённый генератором костюм остаётся отдельным концептом без игрового атласа.

- [Просмотр реальных анимационных атласов](concepts/worm-skins-animated.html)
- [Поставка, оружие, ограничения и проверки](worm-animations.md)
- Арт: `apps/client/public/assets/skins/`, 34 PNG / 532 записи.
- Мастера дополнения: локальные `assets-in/skins/<id>.png`.
- Встроенный imagegen; точные запросы и стиль-референсы —
  `tools/art/skin-roster-prompts.mjs`, ремонт интервалов — `tools/art/skin-roster-repairs.json`.

Браузерная матрица охватывает 12864 сочетания (32 × 67 видов × 2 направления × 3 угла).
Каждый класс дополнительно запускается через меню: проверяются четыре уникальных участника
и сохранение их идентичностей в записи повтора. Матрица проверяет рендер, не баланс оружия.
