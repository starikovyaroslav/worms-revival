# Меню v2: постановочные команды и Revival Brush

Предыдущая реализация лишь отдалённо повторяла концепт: атласные игровые позы
не работали как меню-портреты, Caveat менял характер надписей, а вертикальные
поля под картой разрушали композицию. Эта поставка исправляет именно эти отличия.

## Отдельные иллюстрации команд

Сгенерированы встроенным imagegen десять цельных тройных портретов: девять
классов и смешанный состав. Это самостоятельная меню-графика, не игровые
спрайты. Мастера и точные промпты: `concepts/comic-menu-v2/teams/`.
Экспорт: `apps/client/public/assets/team-previews/`, исходные RGBA-пиксели
сохранены 1:1, добавлен прозрачный запас по краям, без изменения палитры.
Каждая иллюстрация имеет ширину не менее 1500 px. Экспорт — `node tools/art/team-previews.mjs`.

Иллюстрация выбирается по классу команды. При изменении отдельных участников
она остаётся представительным образом класса, а не обещанием точного состава.
Это явно сказано в подсказке кнопки. Нажатие открывает настоящий редактор состава.
Для legacy используется классический портрет, для неизвестного класса — смешанный.
Класс не меняет движение, урон и другие правила.

## Собственный шрифт

Создан Revival Brush Bold, не производный Caveat. Два оригинальных листа
кириллицы/латиницы с цифрами сгенерированы встроенным imagegen по характеру
заголовков концепта. Из альфа-масок построены векторные контуры с сохранением
внутренних просветов; пунктуация сделана отдельными нативными контурами.
Собраны настоящие TrueType и WOFF2 с метриками, Unicode cmap и кернингом.

Это **акцидентный unicase-шрифт**: 100 глифов, 169 кодовых точек; строчные
кириллица/латиница намеренно используют формы прописных. Есть Ё/Й, цифры,
основная пунктуация. Он используется в заголовках, действиях и HUD, но не
в длинных мелких пояснениях. Это не универсальный набор для всех языков.
TTF и WOFF2 лежат в `apps/client/public/fonts/`; WOFF2 около 21 KB.
Caveat с лицензией перенесён в `concepts/comic-menu-v2/archived-font/`,
больше не поставляется из public и не загружается интерфейсом.

Исходники: `concepts/comic-menu-v2/font/`: листы, точные промпты, SVG-контуры,
покрытие символов и образец. Сборка без API и без стороннего шрифта-основы:

```sh
python3 -m venv assets-in/font-build-venv
assets-in/font-build-venv/bin/pip install -r tools/art/requirements-font.txt
WR_FONT_PYTHON=assets-in/font-build-venv/bin/python npm run art:font
```

## Композиция и управление

Крупные лица собраны в одну композицию; лишние кадры атласа и обрезанные
«миниатюры в ячейках» больше не используются. Добавлены наклонный разделитель,
угловой срез превью и более крупная типографическая иерархия. Тема, тип и схема
стоят одной строкой; seed и описание схемы убраны в раскрываемые параметры.
Схема Intermediate показывается как «Классика», её ID и правила не изменены.
Начальные команды теперь демонстрируют спецназ и пенсионеров, как в концепте.

Карта остаётся реальным превью геометрии, а не нарисованным островом из концепта.
Это намеренное оставшееся различие. На коротких десктопах запуск закреплён;
на узких экранах меню складывается в прокручиваемую колонку. Есть раскладка
для 3–4 команд. Точные настройки по-прежнему доступны с клавиатуры.

## Проверки

Арт-тест проверяет все десять превью, прозрачность, цветовую глубину и размеры;
читает cmap из настоящего TTF и проверяет кириллицу, латиницу, цифры и unicase;
тест трассировки проверяет сохранение внутренних просветов букв.
Проверка браузером переключает все десять классов, декодирует изображения,
проверяет размеры меню, работу состава, запуск и возврат; HUD проверяется
на четырёх темах, разных DPR и всех 67 видах оружия.

`npm run check`, `npm run art:test`, `npm run build`,
`node tools/art/comic-menu-check.mjs`, `node tools/art/painted-hud-check.mjs`.
Эти проверки подтверждают работоспособность, не заменяют художественную оценку.
