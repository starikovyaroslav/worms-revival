# Детализация ассетов для десктопа — 2026-10-21

Прежний экспорт слишком рано уменьшал исходные листы до 256×256. Это уничтожало детали
до нарезки: большой исходник не помогал, когда целый самолёт оставался шириной 64–128 px.
Теперь 80 кадров VFX и новой авиации экспортируются из оригинальных листов без такого промежуточного шага.
Новые изображения здесь не генерировались: переработаны сохранённые полноразмерные imagegen-мастера.

## Контракт размеров

В `AssetManifest.assets[id]`:

- `w`, `h` — размер отображения в единицах игрового мира / логического экранного слоя;
- `pixelW`, `pixelH` — физические размеры PNG, не размеры коллизии;
- старые пакеты без `pixelW/pixelH` продолжают работать как 1×.

Например, `attack_0`: `w: 128, h: 56, pixelW: 384, pixelH: 168`.
В мире/экранном логическом слое самолёт остаётся шириной 128 единиц, но текстура содержит
384 настоящих пикселя по ширине. На Full HD / DPR 1 / базовом масштабе — 384 CSS px.
На 1440p — 512 CSS px. Это увеличение отображения, а не изменение карты или физики.

`AssetStore.sizeOf/scaleOf`, `artSprite` и `ClipEffects` применяют этот контракт.
Отдельно исправлены потребители с собственным масштабом: самолёты, прокси сброса,
дымовые частицы с `fixed`, газ, метка отравления и струя ранца. Тени самолётов считают
покрытие в логических единицах, а не расширяются вслед за физической текстурой.

Логический viewport 640×360 и сетка физики не менялись. Они больше не задают верхнюю границу
детализации новых текстур. Персонаж или ракета не становятся крупнее лишь из-за увеличения PNG.

подробные мастера. Старый персонаж, оружие в руках, базовые иконки, фон и земля этим проходом
не перерисовывались: их детализация остаётся отдельным этапом.

## Конвейер

1. Читать неизменённый мастер из `assets-in/military/` или `assets-in/vfx/`.
2. Нормализовать палитру DB32 и альфу **без пространственного уменьшения**.
3. Нарезать кадры по проверенным границам, пересчитанным в родные размеры мастера.
4. Один раз подогнать последовательность под целевой размер, сохраняя общую шкалу и привязку.
5. Записать логический и физический размеры в манифест; исходный crop и масштаб — в `acceptance.json`.

Не используется увеличение прежних маленьких PNG. Плотность задаётся `VFX_DENSITY = 4`
и `MILITARY_DENSITY = 3` в `vfxCatalog.ts`. Экспорт: `npm run art:vfx` / `npm run art:military`.
Размеры холстов — бюджеты текстур; качество всё равно ограничивается реальными деталями мастеров.

## Авиация и модификации

Новый военный пакет — пятый необязательный overlay `assets/military`, 16 PNG.
Предыдущие самолёты не удалены: это fallback при недоступности нового пакета.
Промпты: `tools/art/military-sources.json`; исправление обрезанного хвоста C-130 —
`military-repairs.json`, исходный и исправленный листы сохранены отдельно.

- Обычный налёт и напалм используют attack; тяжёлые специальные сбросы — gunship;
  событие применения ядерного испытания — декоративное летающее крыло stealth.
- Разные темпы пролёта, редкие красные огни, ведущая тень только на суше, синтезированный
  звук двигателей с панорамированием. Падение физических боеприпасов не перепланировано.
- Существующая сила оружия 4–5 звёзд или уже активный Double Damage помечают внешний вид Mk II.
  Никакого нового множителя урона эта метка не добавляет. Она сохраняется при отложенном взрыве.
- Базука/самонаводящаяся ракета Mk II получают другой корпус, более широкую струю и густой след,
  отдельную слоистую вспышку с поздними комьями земли и пылью, тяжёлый запуск и короткое
  приглушение высоких частот при близком попадании. Никакого писка в ушах или постоянного глушения.

## Проверка

- Unit-тесты: одинаковый размер sprites/flipbooks при 1×, 3×, 4×; переключение кадров не меняет его.
- Арт-тесты: физические PNG-размеры отдельно от логических, DB32/альфа, анимации,
  сохранение единичной детали исходника при native crop.
- `node tools/art/desktop-check.mjs`: Full HD, 1440p и Full HD / DPR 2, с CRT и без;
  384-пиксельный самолёт, обе ракеты, взрывы, огонь, газ, метка яда, ранец и бумажные частицы.
  Проверяет ширину в мире, коллизии и неизменность хеша при отрисовке.
- `node tools/art/vfx-check.mjs` / `node tools/art/arsenal-check.mjs`: потребители,
  авианалёты, жизненный цикл, бюджеты, отключение пакетов и отсутствие ошибок браузера/WebGL.
- `npm run check`, `npm run art:test`, `npm run build`, `npm run test:determinism`.
- Снимки игры: `assets-in/previews/desktop/`; сравнение до/после при равном размере —
  `assets-in/previews/military/attack-density-comparison.png` (сверху прежний, снизу новый).
