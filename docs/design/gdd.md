# Game Design Document

## Видение

Пошаговая артиллерия в духе Worms World Party / Armageddon в браузере. Ценности:

1. **Ощущение W:A**: ходьба-«гусеница», характерные дуги, отскоки, ветер, ритм «выстрел — убегай».
2. **Простые правила, глубокая игра**: никаких новых систем, которые нужно учить, ради «контента».
   Глубина — из физики, ландшафта и комбинаций оружия.
3. **Бесконечная реиграбельность**: генерация карт по seed, схемы, Wormpot, боты, челленджи.
4. **Юмор**: овцы, ослы, старушки, фразы червяков, надгробия.

## Основной цикл

Матч → раунды → ходы. В ход: (hot-seat) → движение/подготовка → выстрел → retreat →
разрешение (взрывы, падения, утопления) → конец хода (урон в полоски, смерти) → следующая команда.

## Управление (десктоп, как в W:A)

| Действие              | Клавиша                        |
| --------------------- | ------------------------------ |
| Ходьба                | ← →                            |
| Прицел                | ↑ ↓                            |
| Прыжок / сальто назад | Enter / Enter×2                |
| Огонь (зарядка)       | Пробел (удерживать)            |
| Фитиль                | 1–5                            |
| Отскок                | − / +                          |
| Панель оружия         | ПКМ, F1–F12 (повтор — по ряду) |
| Цель                  | ЛКМ (для наводимых)            |
| Камера                | мышь у края / перетаскивание   |
| Пропуск хода          | (через панель)                 |

Все клавиши переназначаемые. Ввод → абстрактные команды; тач-схема добавится поверх.

## Тюнинг и апгрейды

1. Power 1–5 на оружие (урон, радиус).
2. Апгрейды-тумблеры: Upgraded Grenade / Shotgun / Clusters / Longbow, Aqua Sheep (+ наши).
3. Продвинутый редактор оружия в духе Worms 2 — правка «сырых» параметров.
4. Wormpot — до 3 модификаторов матча.
5. (Опционально) «Мастерская»: детали из ящиков → варианты оружия. Флаг схемы.

## Реиграбельность

- Карты: seed × тип (остров/пещера/мосты) × тема. Импорт PNG и редактор — позже.
- Схемы-пресеты: Intermediate, Pro, Elite, BnG, Hysteria, Shopper, Fort, Armageddon.
- Wormpot, боты 5 уровней, ежедневный seed-челлендж, тренировки с медалями.
- Реплеи: лог ввода, можно делиться.

## Стиль

Яркий мультяшный WWP-стиль: толстая обводка, насыщенные цвета, параллакс-фоны,
волнистая вода. Червяк процедурный (контур-«сосиска», глаза, эмоции), squash & stretch.
Темы: луг, пустыня, арктика, кухня, хэллоуин, свалка, космос.

## Вне скоупа

Техника, здания, классы червяков, 3D, прокачка аккаунта с влиянием на баланс.
