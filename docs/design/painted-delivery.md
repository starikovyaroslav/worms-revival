# Рисованный облик v2 — поставка 2026-10-22

Уточнение статуса интерфейса: первоначальная поставка включала только кодовое
оформление, а не законченный тематический UI-набор. Теперь подключён
[комиксный HUD и переработанное меню](combat-comic-ui-delivery.md), после отклонения декоративного
пилота. Арсенал и диалоги остаются отдельным незавершённым художественным этапом. Числа ниже относятся к исходной
поставке мира и общего набора, без четырёх новых HUD-корпусов.

Утверждённый ориентир — [первый пилот с крупными персонажами](concepts/visual-pilot-v2/meadow-pilot-v1.png).
По просьбе владельца стиль перенесён на остальной активный визуальный набор.
Рисованный режим теперь включён **по умолчанию**; `?visual=pixel` оставляет прежний вид.
Параметр `?visual=painted` остаётся совместимым. Зум при старте — 2×, колесо позволяет
отдалить камеру. Хитбоксы, геометрия карт, оружие, урон и формат повторов не изменены.

Итого рисованный набор — 257 уникальных PNG. В этой поставке добавлен 231 PNG сверх
первого луга. Общая папка содержит 993 PNG вместе с сохранёнными резервными пакетами.
292 записи общего overlay повторно используют одни и те же PNG, не дублируя файлы.
Аудит: [asset-density-audit.json](asset-density-audit.json), незарегистрированных PNG нет.

Все 67 используемых видов оружия имеют новую иконку; дополнительно сохранена иконка
исторического `madcow`. Новые предметы включают ящики всех типов, закрытый/открытый/
сломанный ящик, бочку и горящую бочку, включённую/выключенную мину, четыре могилы,
парашют, динамит, канистру, бутылку и реактивный ранец. Обновлены овца/суперовца,
голубь, крот, корова, осёл, скунс, старушка, монашка, банан и французская овца.

Оружие в руках получает отдельные рисованные текстуры. Размер пистолета остаётся
меньше РПГ, тяжёлое оружие опущено к нижнему хвату, РПГ вынесен вперёд/ниже лица.
Миномёт собран из отдельного основания и горизонтально ориентированного ствола:
опора не вращается вместе с прицеливанием и не подпрыгивает при дыхании.

Полный действующий каталог VFX получает рисованные кадры: обычный/осколочный/огненный/
энергетический/ядерный взрыв, огонь, дым, пар, яд, призрак, копоть, выхлоп, письма,
обычные/управляемые/усиленные ракеты. Для авиации — узнаваемые стилизованные A-10,
AC-130 и B-2, четыре кадра огней/открытия отсека/сброса. Старые cargo/mailplane
сохранены как совместимые ссылки на военный транспорт, не возвращают милые самолётики.
Это художественные прототипы силуэтов, не точные технические модели самолётов.

Мелкие процедурные частицы тоже переключены: мягкие искры, пламя, вспышки и кольца,
объёмные осколки, плавный tint без DB32-снаппинга. Всплеск рисуется мягким кольцом,
не пиксельной процедурной анимацией. Вспышки/слепые пятна/галлюцинации остаются
существующими шейдерными эффектами, а не ненужными дубликатами в PNG.

## Интерфейс и рендер

Меню, HUD, панель оружия и диалоги используют общий кодовый стиль: обычный читаемый
шрифт, тёплый светлый текст, тонкие края и мягкие панели. Новый логотип — `Worms revival`.
Подписи здоровья/имён, стрелка хода, реплики, числа урона и прицел больше не построены
из крупных пиксельных квадратов. Это настоящие UI-элементы с данными симуляции.

36 утверждённых персонажей и их 576 поз **не перегенерированы**: они и были ориентиром.
Сглаживание их атласов и новое окружение согласованы через linear-семплинг.
Палитровой квантизации, пороговой альфы при экспорте и уменьшения общего арта до
маленького мастер-растра нет. Общие спрайты копируют исходные изолированные texel-ы
в новый холст без ресайза. Только полосы материалов нормализуются к контракту рендера.

Декоративная альфа земли сохраняется над поверхностью, но полупрозрачная кромка
композится поверх непрозрачной почвы внутри твёрдой маски: не возникает ложных дыр.
Камень и сталь получают рисованные материалы. Копоть имеет отдельную плотность 3×
и каждый раз обрезается актуальной физической маской. Маска столкновений всё ещё
пиксельная; её ступени на очень крупном зуме не объявляются новой гладкой физикой.

Текстуры одного PNG имеют отдельный view для каждого runtime-id: общие GPU-пиксели
не означают общих размеров в мире. Переключение overlay не уничтожает резервные текстуры.
Обычная загрузка использует новые пакеты и атласы скинов; сотни старых body/hold/spin
кадров не грузятся без необходимости. При неполном наборе, отсутствии скинов либо
`?visual=pixel` подключается прежний конвейер. Старые файлы намеренно сохранены.

## Генерация и воспроизведение

Использован **встроенный imagegen**, не CLI/API. 39 запросов основных мастеров и одна
правка компоновки иконок. Референс роли «стиль», не материал для нарезки целой сцены.

- Полные запросы: `tools/art/painted-expansion-prompts.json`.
- Генератор инвентаря запросов: `tools/art/painted-expansion-prompts.mjs`.
- Правка одного листа: `tools/art/painted-icons-3-repair.prompt.txt`.
- Экспорт: `tools/art/painted-biomes.mjs`, `painted-common.mjs`, существующий `painted-meadow.mjs`.
- Происхождение/хеши мастеров и приёмка RGBA — `generation.json`/`acceptance.json` каждого пакета.
- Локальные исходники: `assets-in/painted-expansion/`, как и прежние входы конвейера, игнорируются git.

```sh
npm run art:painted   # нужны сохранённые локальные мастера
npm run art:test
npm run check
npm run build
# При запущенном Vite:
node tools/art/painted-meadow-check.mjs http://127.0.0.1:5174/ --all
node tools/art/skin-game-check.mjs http://127.0.0.1:5174/
```

## Границы приёмки

Сохранённые результаты: [все темы](concepts/painted-release-v2/themes.png),
[меню](concepts/painted-release-v2/menu.png), [живой взрыв](concepts/painted-release-v2/live-explosion.png).
Машинные отчёты: [матрица матчей](concepts/painted-release-v2/match-acceptance.json),
[весь арсенал на скинах](concepts/painted-release-v2/arsenal-acceptance.json).
Проверки: 343 теста проекта, 29 арт-тестов, типизация/ESLint/production-сборка;
четыре темы × 1280/1920 × DPR 1/2 × CRT off/soft, кратеры и вода. Контрольная симуляция
с теми же командами имеет тот же hash. 14 472 сочетания скин/оружие/направление/угол,
классовые составы и повторы проходят без ошибок. Старый fallback и отсутствие скинов
проверены отдельно. Сохраняется прежнее предупреждение о JS-чанке >500 kB.

Арт-миграция активного набора выполнена; она не означает, что каждый скриншот в точности
повторяет концепт. Карта по-прежнему генерируется из seed, камера приближена к активному
червю, а не держит три концептных фигуры в постановочной композиции. Баланс и физика не
улучшались под видом визуальной задачи. Старый fallback может выглядеть иначе при
повреждённой/неполной загрузке — это аварийная совместимость, не второй активный арт-пакет.

Дальше — продуктовая приёмка полного цикла матча, оптимизация загрузки/атласов и
точечная настройка читаемости эффектов в интенсивном бою, а не ещё один общий арт-ресет.
