# Дизайн-ревью интерфейса (v1)

Дата: 2026-10-08. Оценка по экранам, снятым с текущего билда. Критерии: читаемость, удобство, соответствие
атмосфере «весёлой, но дорогой» игры, эффектность. Оценки 1–5.

## Общий вердикт

Функционально — рабочий каркас; визуально — **«админка»**, а не игра: тёмно-синие карточки, системный
шрифт, эмодзи вместо иконок, нет рамок/текстур/глубины, нет анимации появления. Нужен единый визуальный
язык (см. ниже) и ассетная база (иконки, рамки, шрифты).

## Единый визуальный язык (предложение)

- **Шрифты:** жирный «мультяшный» заголовочный (рукописный/гротеск с характером) + читаемый текстовый.
  Кириллица обязательна. Кандидаты проверить на лицензию (SIL OFL): _Bangers_, _Lilita One_, _Rubik_,
  _Nunito_, _Russo One_.
- **Материал UI:** «деревянные/картонные» панели с обводкой и бликом, а не тёмное стекло; цвета команд
  — основной акцент.
- **Иконки:** один набор, один штрих, одна светотень, SVG или атлас; никаких эмодзи.
- **Анимация интерфейса:** пружинные появления, наведение «приподнимает», нажатие «вдавливает»;
  звук на каждое действие.
- **Адаптивность:** масштабирование HUD по размеру экрана, безопасные поля, режим для ультрашироких.
- **Доступность:** контраст, цветовые метки команд + узоры, масштаб текста, переназначение клавиш.

## Приоритеты

1. HUD боя (виден всегда): таймер, команды, ветер, оружие.
2. Панель оружия (используется каждый ход).
3. Главное меню и экран победы.
4. Настройки, «как играть», загрузка.

Блокирует всё: **единый арт-набор иконок/рамок/шрифтов** (см. `asset-sources.md`, вопрос об источнике арта).
