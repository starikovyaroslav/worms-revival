# Единый рисованный стиль v2

Статус: **владелец утвердил направление с крупными персонажами**.
После приёмки луга стиль перенесён на остальной активный набор и включён по умолчанию.
Текущий статус, проверки и границы: [рисованная поставка v2](painted-delivery.md).
Концепт остаётся ориентиром, не обещанием покадрового совпадения каждого матча.

[Открыть сравнение с HUD и настоящим CRT игры](concepts/visual-pilot-v2/review.html).
Быстрый просмотр: [пилот с HUD без CRT](concepts/visual-pilot-v2/pilot-hud.png).
Страница работает локально без сервера: обе сцены встроены как изображения;
нужен браузер с WebGL2. [Сцена без интерфейса](concepts/visual-pilot-v2/meadow-pilot.png).

## Направление

Гротескная рисованная 2D-артиллерия с характером игр 2000-х: выразительные взрослые
персонажи, преувеличенное оружие, объёмные материалы и ясные силуэты.
Не фотореализм, не крупнопиксельная стилизация и не кинематографический постер.
Высокое разрешение нужно для чистого рисунка, а не для одинаково мелкой фактуры везде.

Приоритет чтения: персонаж и оборудование → игровая кромка → действие/взрыв →
внутренний срез земли → дальние планы. Вспышка может кратковременно быть самой яркой,
но дым не должен надолго скрывать прицел и соседних персонажей.

| Элемент       | Целевой художественный контракт                                                                                                                                           |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Персонажи     | Сохранить утверждённые лица, возраст, телосложение и характер. Обобщать складки и волосы в читаемые массы; мелкие детали — акценты, не сплошной шум.                      |
| Контур и свет | Тонкий тёмный цветной контур, ясный внешний силуэт, общий ключевой свет сверху-слева. Без тяжёлого чёрного обрамления каждой внутренней детали.                           |
| Оружие        | Пистолет явно меньше РПГ, миномёт на собственной опоре. Узнаваемые, слегка преувеличенные формы; ограниченные блики на металле, не фотореалистическая модель.             |
| Земля         | Крупные пласты, редкие большие камни и корни у кромки. Чёткая игровая граница. Не равномерная зернистость, сетка или одинаковый шум по всему срезу.                       |
| Фоны          | Тот же язык рисунка, но проще, холоднее и ниже по контрасту. Три различимых плана; облака округлые рисованные, без крупных пиксельных ступеней.                           |
| Вода          | Крупные ритмичные волны и немного светлых гребней. Не фотографические отражения и не отдельная «реалистичная» поверхность.                                                |
| VFX           | Компактное светлое ядро, крупные огненные и дымовые массы, немного обломков. Без квадратных пикселей рядом с рисованными персонажами и без фотографического пламени.      |
| HUD           | Компактные тёмные панели, тёплый светлый текст, красный/голубой для команд. Обычный читаемый шрифт; табличные цифры. Не тяжёлая пиксельная фаска вокруг каждого элемента. |
| CRT           | Дополнительная настройка вкуса, не способ скрыть стилистическое несоответствие. Арт обязан работать при выключенном фильтре.                                              |

## Что сделано в пилоте

Одна цельная рисованная сцена: луг, срез земли, три персонажа из существующего направления,
РПГ, пистолет, наземный миномёт, взрыв, дым, след снаряда и вода.
Выбран первый вариант с крупными персонажами: `meadow-pilot.png` совпадает с
`meadow-pilot-v1.png`. Уменьшенная версия сохранена как `meadow-pilot-small.png`,
но не является ориентиром размера. Крупный план в игре — зум камеры 2×,
не увеличенные хитбоксы. Колесом можно вернуться к обзору карты.

HUD — отдельные HTML/CSS-элементы, не текст, нарисованный генератором.
Числа и подсказки демонстрационные, не данные текущего матча и не изменение баланса.
Сравнение «текущее / пилот» показывает разные сцены: базовый кадр — прежний QA-стенд,
пилот — концепт. Это не два рендера одного seed или одного состояния симуляции.

Просмотр использует **тот же фрагментный CRT-шейдер и пресеты, что игра**:
`packages/render/src/crt.ts` и `crtPresets.ts`. В standalone HTML они встроены генератором
страницы, текстуры масштабируются без искажения пропорций. DOM-HUD остаётся отдельным слоем.
Это адаптер шейдера для сравнения изображений, не полный PostFX-проход игрового движка.

## Концепт и играбельный срез — разные результаты

- Сам концепт не является играбельной картой: в PNG запечены персонажи, оружие и эффекты.
- Изображение нельзя нарезать и объявить готовым пакетом тайлов, параллакса и анимаций.
- Три персонажа не означают, что все 36 скинов уже переработаны в новый стиль.
- Standalone-просмотр не проверяет физику, разрушение и анимации. Настоящий матч
  использует отдельные слои, существующие скины/позы и прежнюю симуляцию.
- Сгенерированный рисунок задаёт направление, но не гарантирует соблюдение каждой
  числовой пропорции. Размеры в мире и крепления оружия определяются кодом, не концептом.

## Первый играбельный луг — историческая приёмка

Ниже зафиксированы ограничения **первого** среза до переноса остальных ассетов.
Они больше не описывают текущий набор: все четыре темы и общий пакет уже подключены.
Теперь `/?seed=42&theme=meadow` запускает новый вид по умолчанию;
для прежнего оформления нужно явно указать `?visual=pixel`.

После `npm run dev` открыть `/?visual=painted`, выбрать тему «Луг», классы и начать матч.
Быстрый запуск: `/?visual=painted&seed=42&theme=meadow`.
Без параметра игра использует прежние пакеты и даже не загружает новый.
Другие темы и неполный/недоступный пакет возвращают старое оформление и обычный зум.

26 PNG в `apps/client/public/assets/painted-meadow/`: небо, три отдельных плана,
заливка почвы, четыре кромки, вода и по четыре кадра взрыва, дыма, обломков, огня.
Пакет имеет собственный namespace, исходные цвета и непрерывную альфу PNG;
DB32-квантизация не применяется. Семплинг linear включается только для нового пакета
и скинов в этом режиме; размеры в мире не зависят от PNG. Рельеф всё ещё рисуется
по прежней пиксельной маске столкновений, поэтому на большом зуме возможны ступени
по границе кратера. Это отдельная будущая задача визуального сглаживания, не новая физика.

Взрывы/осколочные клипы, частицы дыма и мировой огонь подключены к новому пакету.
Специальные эффекты другого типа используют целый прежний клип, не смесь кадров.
HUD получает отдельные компактные панели и обычный шрифт, но показывает реальные
таймеры, здоровье и оружие. Мир/CRT и DOM-интерфейс остаются разными слоями.

Ещё не обновлены: все биомы кроме луга, оружие/авиация, ящики/бочки/мины, специальные
VFX, мелкие процедурные частицы, пиксельные игровые подписи над персонажами и меню.
Существующие 36 скинов не перегенерированы: это исходный ориентир нового окружения.
Нельзя считать весь арт-проход завершённым или включать этот пакет глобально без приёмки.

Экспорт: `node tools/art/painted-meadow.mjs` (нужны локальные мастера
`assets-in/painted-meadow/`, они игнорируются git, как и другие входы арт-конвейера).
Точные запросы и входной референс: `tools/art/painted-meadow-prompts.json`;
генерация — встроенный imagegen. Производственные PNG и manifest сохранены в git.
Проверка настоящего матча: `node tools/art/painted-meadow-check.mjs` при запущенном Vite.
Скриншоты/отчёт: `assets-in/previews/painted-meadow/`, сохранённая копия приёмки —
`concepts/visual-pilot-v2/live-acceptance.json`.

## Этапы первого пилота (продолжены общей поставкой)

1. Утверждено: зафиксирован крупный вариант как стиль-референс.
2. Подключён **играбельный вертикальный срез луга** из отдельных ассетов: земля/кромка,
   небо и три плана, вода, три существующих скина, выбранное оружие и один набор VFX.
   Геометрия и коллизии останутся прежними. Сначала параллельный пакет, не перезапись всех PNG.
3. Добавлен отдельный smooth-семплинг без изменения nearest для остальных пакетов.
   Следующий визуальный проход — подписи, объекты и кромки на крупном зуме.
4. Сравнить настоящий матч при 1280×720 / 1920×1080, DPR 1/2, с CRT и без, обычным зумом
   и приближением. Проверить контур кратеров, швы, руки/оружие, лица, HUD и динамический дым.
5. Лишь после приёмки распространять контракт на пустыню, Арктику, ад, существа,
   остальные скины, оружие/авиацию и эффекты. Каждый набор — отдельный коммит и приёмка.

## Исходники и воспроизведение

Генерация — встроенный imagegen с изображениями из репозитория как референсами.
Точные запросы: `tools/art/visual-pilot-v2.prompt.txt` и
`tools/art/visual-pilot-v2-repair.prompt.txt`.
Результаты сохранены в `docs/design/concepts/visual-pilot-v2/`; исходный вариант —
`meadow-pilot-v1.png`, выбранная копия — `meadow-pilot.png`, невыбранная правка —
`meadow-pilot-small.png`, прежний QA-кадр — `before.png`.

```sh
node tools/art/visual-pilot-review.mjs
node tools/art/visual-pilot-check.mjs
```

Проверка страницы: реальный WebGL2, 1280/1920 CSS px, DPR 1/2, все четыре режима CRT,
переключение сцен и HUD, отсутствие выхода панелей за границы и мелкого текста <10 CSS px.
Скриншоты и машинный отчёт: `assets-in/previews/visual-pilot-v2/`.
Сохранённая приёмка: [acceptance.json](concepts/visual-pilot-v2/acceptance.json);
происхождение изображений: [generation.json](concepts/visual-pilot-v2/generation.json).
Вся браузерная матрица пройдена, ошибок WebGL/страницы нет. `npm run check` — 337 тестов,
типизация и ESLint проходят. Production-сборка успешна. Прежнее предупреждение
о JS-чанке >500 kB остаётся. Браузерные проверки не заменяют визуальную приёмку владельцем.

Живой рендер: [матч с крупным персонажем](concepts/visual-pilot-v2/live-match.png),
[кратер и новые эффекты](concepts/visual-pilot-v2/live-crater-effects.png).
Проверки пакета: 26 арт-тестов, аудит плотности без проблем; отдельный браузерный
прогон проверяет 1280/1920, DPR 1/2, CRT off/soft, воду, неизменность состояния при
рендере, совпадение частичной/полной перерисовки кратера и три резервных сценария.
