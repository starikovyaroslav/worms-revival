# Visual direction: «дорогой» визуал и отклик

Статус: **предложение, ждёт подтверждения** (см. открытые вопросы в конце). Исследование от 2026-10-08.

## Диагноз текущего состояния

Графика v1 — векторные примитивы Pixi (круги, градиенты, эмодзи в UI). Отсюда ощущение «каркаса»:

| Что           | Проблема                                                                                 |
| ------------- | ---------------------------------------------------------------------------------------- |
| Червяк        | Склейка кругов; нет объёма, света, текстуры кожи, мимики, характера                      |
| Земля         | Плоская текстура без глубины; края — 1-пиксельная обводка; нет освещения                 |
| Взрыв         | Кружок-вспышка + серые кружки-«дым». Нет огненного шара, ударной волны, искр, копоти     |
| Свет          | Его нет совсем: сцена освещена равномерно, взрыв ничего не подсвечивает                  |
| Фон           | Три однотонных силуэта холмов                                                            |
| Анимация      | Нет приседаний/растяжений при прыжке и приземлении, нет реакции на урон                  |
| Постобработка | Нет: ни bloom, ни цветокоррекции, ни виньетки                                            |
| UI            | Системный шрифт, эмодзи вместо иконок, плоские тёмные плашки (подробно в `ui-review.md`) |

## Принципы «дорогого» вида

Мульти-слойный подход, где каждый слой дешёвый, а вместе они дают «объём»:

1. **Единая палитра и свет.** Тёплый ключевой свет сверху-слева, холодная заливка; каждая тема —
   своя цветокоррекция (LUT). Контраст читаемости: червяки и снаряды всегда ярче фона.
2. **Глубина.** 4–5 слоёв параллакса с атмосферной перспективой (дальше — светлее и холоднее),
   плывущие облака/частицы, дальний «туман» над водой.
3. **Материальность.** Земля с бликами на краях, травой/снегом по верхней кромке, корнями и камнями
   в толще; кратеры с копотью и тлеющими краями.
4. **Свет как эффект.** Взрыв, огонь, ракета, ящик с парашютом — источники света; общий bloom.
5. **Сок (juice).** Каждое событие отзывается 4+ каналами: визуал, звук, камера, пауза/замедление.

## Решения по технологиям

### Анимация: гибрид, а не один подход

| Подход                         | Где применяем                                                 | Почему                                                                                                                                             |
| ------------------------------ | ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Мягкое тело на мешe**        | Тело червяка                                                  | Червяк — «колбаска»: сегменты на цепочке + текстура кожи (`MeshRope` в Pixi) даёт squash&stretch, ползание, смерть-«шлёпок» бесплатно и в 60 FPS   |
| **Покадровые атласы**          | Лицо/глаза/рот, руки, оружие в руках, взрывы, огонь, дым      | Лучший вид для «рисованных» эффектов и мимики; просто, быстро, предсказуемо                                                                        |
| **Спрайты со статичной позой** | Снаряды, ящики, мины, бочки, надгробия, шапки                 | Достаточно вращения и сквоша в коде                                                                                                                |
| **Spine (скелетная)**          | **Не сейчас.** Резерв для сложных персонажей (боссы, техника) | Лицензия: Essential $69 **без мешей**; Professional $379 — с мешами; нужна на каждого аниматора. Для червяка избыточно, а мягкое тело делаем кодом |
| **Шейдеры**                    | Земля, вода, постобработка, свет                              | Дешёвый «дорогой» вид без лишних спрайтов                                                                                                          |

Вывод: **червяк = мягкое тело (код + текстура) + лицо/аксессуары из атласов**. Это сохраняет «живость»
оригинала (тело гнётся и пружинит), а вручную рисовать нужно только текстуры и атласы лица.

### Освещение: карта света, а не карты нормалей на всё

`pixi-lights` рассчитан на старые версии Pixi; в v8 кастомные нормал-карты сложны (WebGL+WebGPU).
Поэтому:

1. **Light map (основа).** Рендерим источники света (радиальные градиенты, аддитивно) в `RenderTexture`
   на половинном разрешении; сцена умножается на «ambient + lightmap». Дёшево, работает везде.
2. **Нормали земли из маски.** Ландшафт у нас и есть высотное поле: нормаль считается в шейдере по
   размытой маске (разность соседних значений) → объёмные края и блики **без единого рисованного normal map**.
3. **Нормал-карты для спрайтов — отложены.** Сложность 5/5, выигрыш для мультяшного арта малый.

### Эффекты и постобработка

- `pixi-filters` v6 (под Pixi v8, MIT): `AdvancedBloomFilter`, `ShockwaveFilter`, `GodrayFilter`, `GlowFilter`,
  `AdjustmentFilter`. Берём готовое, пишем свои шейдеры только для земли и воды.
- Искажение от взрыва: `ShockwaveFilter` (или displacement-карта) на сцену, на 0.4–0.6 с.
- Частицы: `@pixi/particle-emitter` v6 (Pixi v8) или RevoltFX (есть онлайн-редактор эффектов).
  Эффекты описываются конфигами (JSON), чтобы художник/дизайнер правил без кода.
- Рецепт взрыва ракеты (слои по времени): вспышка 0–2 кадра → огненный шар (атлас) → ударная волна +
  displacement → искры и угли с гравитацией → осколки земли (физические, оседают) → дым 1–2 с с
  подсветкой снизу → копоть на земле (маска) → тлеющий кратер. Свет: белый → оранжевый → гаснет.

### Игровой отклик (juice)

Опираемся на «Juice it or lose it» (Jonasson, Purho, 2012) и «The Art of Screenshake» (Nijman, Vlambeer, 2013).
Таблица событий → каналов (минимум для каждого):

| Событие           | Камера                   | Время             | Звук                   | Визуал                       | UI                         |
| ----------------- | ------------------------ | ----------------- | ---------------------- | ---------------------------- | -------------------------- |
| Выстрел           | отдача (короткий толчок) | —                 | хлопок + затвор        | вспышка у дула, гильза/дым   | —                          |
| Попадание в червя | тряска по силе урона     | hit-stop 60–90 мс | удар + реплика         | squash, белая вспышка, искры | число урона «подпрыгивает» |
| Взрыв             | тряска + зум-панч        | замедление 0.3 с  | слои: удар/треск/хвост | см. рецепт выше              | —                          |
| Убийство          | зум на жертву            | замедление 0.6 с  | драматичная нота       | самоподрыв, надгробие падает | полоска команды «трясётся» |
| Начало хода       | плавный перелёт          | —                 | гонг                   | подсветка активного червяка  | баннер имени               |
| Последние 5 с     | лёгкий пульс             | —                 | тики, ускоряются       | красная виньетка             | таймер пульсирует          |

### Адаптивная музыка и звук

- **Вертикальные слои** (стемы одной темы, синхронно): фон/пад → ритм → перкуссия → мелодия/бас.
  Уровень слоёв определяет «интенсивность боя» из состояния игры: недавние взрывы, число раненых,
  здоровье команд, внезапная смерть, таймер < 10 с. Переходы — на границе такта.
- **Горизонтальные переходы** между темами: меню → выбор карты → бой → победа/поражение.
- Звук: слои на событие, реверберация по типу окружения (пещера/остров), позиционирование (уже есть),
  ducking музыки под взрывы.
- Реализация: WebAudio, стемы как `.ogg/.m4a`, синхронизация через общий `AudioContext.currentTime`.

## Архитектура анимаций и спрайтов (конфиги)

Всё, что видит игрок, описывается данными в `assets/` и `packages/content`, а не кодом.

```
assets/
  manifest.json                # что грузить к каким экранам (меню/бой), версии, хеши
  atlases/
    worm-face.json + .png      # TexturePacker/Pixi-совместимый атлас
  anim/
    worm-face.anim.json        # клипы и события
    fx-explosion.anim.json
  fx/
    explosion-rocket.fx.json   # рецепт эффекта (слои, частицы, свет, шейдер, звук, камера)
  themes/
    meadow.theme.json          # палитра, слои фона, LUT, текстуры земли, настройки света
  audio/
    bank.json                  # id → файлы, громкость, варианты, слои
```

**Клип анимации** (`*.anim.json`) — расширение формата атласов Pixi (`animations`):

```jsonc
{
  "atlas": "worm-face",
  "clips": {
    "idle": { "frames": ["idle_00", "idle_01", "idle_02"], "fps": 6, "loop": true },
    "blink": {
      "frames": ["blink_0", "blink_1", "blink_2"],
      "fps": 24,
      "loop": false,
      "next": "idle",
    },
    "hurt": {
      "frames": ["hurt_0", "hurt_1"],
      "fps": 12,
      "loop": false,
      "events": { "0": "flash" },
    },
  },
  "anchors": { "hand": { "idle_00": [4, 9] } }, // точки привязки (рука, дуло) по кадрам
  "states": {
    // связь с состоянием симуляции
    "idle": { "clip": "idle", "random": { "blink": 0.01 } },
    "airborne": { "clip": "fall" },
  },
}
```

**Рецепт эффекта** (`*.fx.json`) — слой за слоем, по времени:

```jsonc
{
  "id": "explosion-rocket",
  "scale": "blast.radius",
  "layers": [
    { "at": 0.0, "type": "light", "color": "#fff2c0", "radius": 2.4, "fade": 0.35 },
    { "at": 0.0, "type": "anim", "clip": "fx-explosion/fireball", "blend": "add" },
    { "at": 0.0, "type": "shockwave", "amplitude": 30, "duration": 0.5 },
    { "at": 0.0, "type": "particles", "preset": "sparks", "count": 24 },
    { "at": 0.05, "type": "debris", "material": "terrain", "count": 18 },
    { "at": 0.1, "type": "particles", "preset": "smoke", "count": 10, "lit": true },
    { "at": 0.0, "type": "camera", "shake": 0.8, "punchZoom": 0.04 },
    { "at": 0.0, "type": "time", "scale": 0.35, "duration": 0.2 },
    { "at": 0.0, "type": "sound", "id": "explosion-medium" },
    { "at": 0.0, "type": "scorch", "radius": 1.1 },
  ],
}
```

Загрузка: манифест → `Assets.load` пакетами (меню отдельно от боя) → кэш в IndexedDB → валидация конфигов
схемой (Zod) на старте → понятные ошибки. Схема тем (`*.theme.json`) аналогична.

**Правило:** симуляция знает только id события (`explosion`, `splash`, `sound`…) и параметры (радиус,
сила). Какой именно эффект играется — решает слой презентации по конфигу. Это позволяет менять вид без
риска сломать детерминизм.

## План реализации — Фаза V в `docs/ROADMAP.md`

Порядок, при котором результат виден как можно раньше:

1. **V3a Bloom + цветокоррекция + виньетка** (1 коммит, мгновенный эффект на всё).
2. **V4a Рецепт взрыва** (слои, свет, ударная волна, осколки, копоть).
3. **V3b Light map** (взрывы/огонь/ракеты освещают сцену).
4. **V1 Загрузчик ассетов и конфиги анимаций.**
5. **V2 Червяк: мягкое тело + лицо из атласа.**
6. **V3c Шейдер земли** (нормали из маски, блики, трава/снег).
7. **V5 UI** по `ui-review.md`.
8. **V6 Адаптивная музыка.**
