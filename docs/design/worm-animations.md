# Классы, персонажи и анимации — 2026-10-22

Статус на 2026-10-23: 16 базовых поз — не полноценные последовательности всех
действий и реакций. Следующий этап описан в
[исследовании пластики и спецификации пилота](worm-motion-research.md).

В игру подключены **36 отдельных персонажей**, по **16 рисованных поз** каждому
(576 кадров). Типаж теперь является классом команды, а не одним скином на всех.
В меню доступны выбор класса и явный выбор образа каждого участника. Образы различаются
лицами, телосложением и одеждой, а не перекрашиванием одного спрайта.

Стандартная команда из четырёх теперь состоит из уникальных образов. Для команды
больше четырёх образы повторяются по кругу. Назначение вручную позволяет выбирать
и повторять образ. [Поимённые составы всех классов](character-rosters.md).

Исходный анимационный запрос доминатрикс отклонён генератором и не повторялся.
Её концепт сохранён отдельно. После согласия владельца добавлена новая неэротическая
«Чёрная командирша» (`commander-femme`) в закрытой матовой полевой форме, с чёрным каре
и властной пластикой. К ней добавлены инспекторша, надзирательница и начальница:
четыре самостоятельных закрытых образа в классе.
Это новый костюм и отдельный id, а не анимация отклонённого наряда. История отказа
сохранена в `tools/art/skin-animation-status.json`.

Новый отдельный класс «Ночные» использует открытые плечи, непрозрачные сценические
корсажи и топы, чокеры и властную пластику. Два латексных образа дополнены портупеями
и свёрнутыми плётками на поясе; два кожаных образа сохраняют исходные костюмы после
отказа генератора в финальных правках. [Состав, ограничения и проверка](nocturne-class.md).

## Анимационная модель

Идентичность → профиль пластики → текущая поза → независимое крепление оборудования.
Профили задают дыхание, покачивание, наклон и отдачу: тяжеловес устойчивее,
мягкотелый пружинит, пожилой сутулится, ветеран движется асимметрично.
Это только внешний вид: скорость, здоровье, баллистика и коллизии одинаковы.

Набор поз: ожидание, моргание, четыре фазы ходьбы, прыжок, падение, приземление,
получение урона, прицеливание, бросок, ближний бой, верёвка, поражение и победа.
Используются рисованные кадры и вторичная процедурная пластика, а не скелетная анимация.
Это не 67 уникальных рисованных роликов стрельбы: общие позы тела сочетаются с
отдельными спрайтами оружия и отдачей. Парашют, заморозка, невидимость и смерть
сохраняют индивидуальность; активный ранец рисует существующий JetPackView.

Для всех **67** зарегистрированных видов оружия/утилит задана роль крепления.
Ширина пистолета — 8 единиц мира, РПГ — 27, минигана — 29 независимо от скина и PNG.
Есть рука, плечо, нижняя точка установки и наземный узел; предусмотрены поправки
к конкретным персонажам. Миномёт имеет отдельные основание и поворачиваемый ствол,
не двигающиеся вместе с дыханием тела. Для налётов используется рация, для удалённых
действий — пульт, а не самолёт в руке. Брошенные/установленные объекты не дублируются
на персонаже во время действия.

## Формат и исходники

- Поставка: `apps/client/public/assets/skins/`, 38 PNG / 596 runtime-записей.
- 36 атласов персонажей по 768×768; ячейка 192×192, размер в мире 32×32 (плотность 6×).
- 16 отдельных изображений оборудования в общем `weapons.png`, ещё 4 части в `equipment.png`.
- Одна шкала и линия опоры на весь набор поз персонажа. Разделение компонентов
  сохраняет поднятые руки и отдельно стоящие костыли; обрезанная кисть classic/throw
  заменена отдельным проверенным ремонтным изображением.
- Исходные RGB и непрерывная альфа сохранены; DB32-квантизации и бинарной альфы нет.
- Атлас загружается один раз, кадры разделяют TextureSource. Отсутствующий пакет
  не ломает игру: остаётся прежний рендер червя.

Режим генерации — встроенный imagegen с концептом конкретного персонажа как референсом.
Точные запросы: `tools/art/skin-animation-prompts.mjs`,
`tools/art/skin-animation-repairs.json`, `tools/art/skin-equipment.prompt.txt`.
Закрытая командирша: `tools/art/skin-commander.prompt.txt`, референс коммандо использован
только для стиля, не для переноса её лица или одежды. Мастер: `assets-in/skins/commander-femme.png`.
Запросы 16 новых участников — `tools/art/skin-roster-prompts.mjs`, исправление тесной
раскладки семи листов — `tools/art/skin-roster-repairs.json`. Неоднозначная нарезка
останавливает экспорт, а не разрезает соединённые руки и костыли по сетке.
Полноразмерные мастера находятся локально в игнорируемом `assets-in/skins/`;
для запуска/production-сборки нужны только поставляемые публичные атласы.
Запросы «Ночных»: `tools/art/skin-nocturne-prompts.mjs`; результаты и отказы записаны
в `tools/art/skin-nocturne-status.json`.
Полный арт игры после дополнения: **736 PNG / 1292 уникальных runtime-id**.

```sh
npm run art:skins
npm run art:audit
npm run art:test
node tools/art/skin-game-check.mjs http://127.0.0.1:5174/
```

Старое поле `skin` в конфигурациях сохранено. Новые поля `characterClass` и
`characterVariants` не попадают в GameSetup и хеш симуляции. Запись повтора фиксирует
разрешённый состав по участникам, чтобы пополнение класса не меняло лица старого матча.

Проверка браузером: 14472 сочетания (36 персонажей × 67 видов × 2 направления × 3 угла),
размеры оружия, опора миномёта, классовый состав, запись индивидуальностей в повтор,
прыжок/падение, верёвка/парашют, реакции и исход матча. Хеш состояния до и после
отрисовки одинаков. Отдельно проверяются отсутствие пакета и локальная страница атласов.
Контактные листы проверены визуально; матрица — проверка контрактов рендера,
не замена живого прохождения всех 67 механик оружия.

Каждый из девяти классов запускается из меню: четыре уникальных образа совпадают
с составом записи повтора. Арт-тест исключает одинаковые силуэты между персонажами
и повторённые кадры вместо четырёх рисованных фаз ходьбы.

Для «Ночных» проверены автоматический и ручной состав с повторением образа, запись
600 тактов движения и выстрела, JSON-сериализация и загрузка `.wrr` через меню.
Идентичности и итоговые хеши обоих повторов совпадают; симуляция совпадает с матчем
без косметических полей.

`npm run check`: 333 теста; `npm run art:test`: 24 теста.
Детерминизм Node/Chromium/Firefox/WebKit: общий итоговый хеш 114089616.
Production-сборка проходит; прежнее предупреждение о JS-чанке >500 kB остаётся.
