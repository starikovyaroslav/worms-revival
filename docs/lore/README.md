# Лор-справочник

Выжимка механик Worms 1 / Director's Cut / Worms 2 / Armageddon / World Party / W.M.D,
собранная из документации сообщества. Это эталон «ощущения» игры, а не спецификация к копированию:
код и ассеты Team17 не используются, исходники W:A не публиковались.

- [mechanics.md](mechanics.md) — движок, ход, червяк, баллистика, ландшафт, ящики, Sudden Death.
- [arsenal.md](arsenal.md) — оружие по рядам панели W:A, отличия поколений, W2-редактор, WMD-крафт.
- [schemes.md](schemes.md) — схемы, опции, известные пресеты и чем они хороши.

Пометка **(≈)** — число не подтверждено первоисточником и подлежит калибровке «по ощущению».

Источники: [worms2d.info](https://worms2d.info) (Worms Knowledge Base),
[worms.fandom.com](https://worms.fandom.com), Wikipedia, readme патчей W:A 3.x.
