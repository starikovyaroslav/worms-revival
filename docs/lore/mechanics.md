# Механики W:A / WWP

## Движок

- Логика — **50 кадров в секунду**, фиксированный шаг. Патч 3.8 добавил интерполяцию только в рендер.
- Физика на fixed-point 16.16 (видно по `1/65536` в формулах). Единицы: пиксели, px/кадр, px/кадр².
- Полный детерминизм: онлайн-игра и реплеи — это лог ввода. Реплей `.WAgame` содержит
  контрольные суммы состояния после каждого выстрела.
- Версии игровой логики хранятся, чтобы старые реплеи проигрывались одинаково.

## Ход

| Параметр     | Значение                                                                  |
| ------------ | ------------------------------------------------------------------------- |
| Время хода   | 45 с (≈) в Intermediate; 30 с Armageddon; 15 с Roper; 1 с Hysteria        |
| Retreat      | 0 / 3 / 5 / 10 с, по умолчанию 5. Отдельно — rope retreat                 |
| Hot-seat     | пауза «на подумать» до старта таймера (Hysteria — 10 с)                   |
| Время раунда | по истечении — Sudden Death                                               |
| Порядок      | команды по кругу, каждая ходит одним червяком; червяки команды — по кругу |
| Worm Select  | выбор червяка в начале хода (опция схемы / оружие Select Worm)            |

- Урон в течение хода показывается всплывающими числами, а **полоски HP команд обновляются в конце хода**.
  Червяки с 0 HP по очереди взрываются (самоподрыв), оставляя надгробие команды.
- Любое попадание по своему активному червяку завершает ход (переход в retreat).

### Sudden Death

- Наступает **между ходами**, через случайное число ходов после окончания времени раунда.
- Событие: конец раунда (побеждает сильнейший) / всем HP=1 / «ядерное» отравление всех / ничего.
- Подъём воды — отдельная опция: `WRSPEED = (WRBYTE² · 5) mod 256` px за ход, «medium» = 20 px.
- Nuclear Bomb / Indian Nuclear Test: вода +120 px (W2) и отравление (W:A).

## Червяк

- **Ходьба** привязана к анимации: 15 кадров, 13 из них двигают червяка на 0…1.75 px,
  цикл ~3 раза в секунду. Это даёт характерную «гусеничную» неравномерность.
- **Подъём**: при упоре в стену проверяется до **8 px вверх** — ступенька проходима.
- **Jump** (Enter): вперёд-вверх. **Backflip** (двойной Enter): выше и короче, назад.
- **Урон от падения** зависит от скорости удара, не от высоты:

  ```
  FDCOEF = (FDBYTE * 50) mod 256        ; FDBYTE = 1 по умолчанию → 50
  DAMAGE = INT(((VSPEED - 8 + 1/65536) * FDCOEF + 18) / 18)
  ```

  `VSPEED` в px/кадр; ниже 8 — без урона. Скорость ограничена 32 px/кадр → максимум 67.
  После отброса взрывом урон от падения не начисляется.

- **Отброс**: червяк летит, скользит по поверхности с трением, может отскакивать.
  Трение, упругость, гравитация — расширенные опции схемы (бывший RubberWorm, в W:A 3.8).
- **Утопление**: касание воды — смерть (без самоподрыва и надгробия).

## Баллистика

- **Ветер**: 21 значение (−10…+10), сила — процент от гравитации. Меняется каждый ход.
  - Влияет: базука, Homing Missile (до захвата), Mortar, газ, огонь (Flamethrower, Petrol, Napalm, бочки),
    ящики, MB Bomb, Mail Strike, парашют, Longbow (≈).
  - **Не влияет: гранаты** (Grenade, Cluster, Banana, HHG) — поэтому граната — ответ на сильный ветер.
- **Сила выстрела**: зажать огонь, полоска заполняется ~1 с (≈), в конце — автоматический выстрел.
- **Фитиль** 1–5 с (цифры), **отскок** min/max (−/+):
  - max: горизонталь −4%, вертикаль −40% за отскок;
  - min: горизонталь −4%, вертикаль −70%.
- **Power** 1–5 у каждого оружия в схеме масштабирует урон и кратер.
  Граната: power 11 → 25 HP / кратер 47 px; power 15 → 100 HP / 199 px (расширенные уровни).
- **Взрыв**: урон спадает от центра; положение относительно хитбокса важно (динамит вплотную — 55–75).
  Точная формула не публиковалась. Модель для калибровки: `dmg = max·(1 − d/r)`,
  отброс — от центра, пропорционально урону (≈).

## Ландшафт

- Пиксельная разрушаемая маска. Снизу вода, бока открыты (можно упасть), верх открыт или потолок пещеры.
- Классический размер карты — **1920×696**; позже до 32512×32600, стороны кратны 8.
- Типы: остров (island) / пещера (cavern), генерация по seed (одинаковый seed — одинаковая карта).
- Индестрактибл-земля (флаг схемы, Shopper-карты), индестрактибл-границы.
- Импорт картинки как карты (64 цвета, `#000000` — пустота), встроенный редактор.
- Объекты при старте: **бочки** (взрыв + горящая нефть, сносимая ветром), **мины**
  (фитиль 0–3 с или случайный, «дуды» только дымят, ~50 урона).

## Ящики

- Оружейный, лечебный (25 HP по умолчанию, до 255; лечит отравление), утилити-ящик.
- Падают на парашюте (сносит ветром). Шанс выпадения каждого типа — опция схемы;
  у каждого оружия свой вес в ящике.
- Утилити-ящики: Double Damage, Crate Spy, Crate Shower, Double Turn Time, Fast Walk, Laser Sight,
  Low Gravity, Jet Pack, Invisibility.
- Reinforcements: ящики-ловушки (5–25 урона) — в W:A убраны.
- **Donor card**: погибший червяк (если последний в команде) оставляет карту с арсеналом команды.

## Режимы

- Быстрая игра, дуэль с CPU, hot-seat, миссии и тренировки (Rifle Range, Artillery Range,
  Super Sheep Racing, Euthanasia…) — золотые медали открывают «читы»-апгрейды.
- Команда: 8 именованных червяков, флаг, надгробие, банк голосов, фанфары победы,
  специальное оружие (выбранное секретно, доступно после N ходов).
- **Wormpot** (WWP): слот-машина до 3 модификаторов на матч (двойной урон отдельных классов оружия,
  скользкая земля, «супер-червяк», 10 с бесплатной стрельбы, бессмертные червяки, и т.д.).

## Подача

- Камера следит за активным червяком, затем за снарядом, потом за повреждениями; свободный скролл мышью.
- Тикающий таймер в последние секунды, ритм «выстрелил — убегай».
- Юмор: фразы червяков (попадание, падение, ожидание, победа), овцы, старушки, ослы, «Аллилуйя» перед HHG.
