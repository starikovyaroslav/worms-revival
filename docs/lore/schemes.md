# Схемы

Схема = опции матча + настройки каждого оружия + апгрейды + расширенные опции.

## Настройки оружия

| Поле  | Диапазон     | Смысл                             |
| ----- | ------------ | --------------------------------- |
| Ammo  | 0–9, ∞       | Стартовый боезапас                |
| Power | 1–5 (звёзды) | Урон и радиус кратера             |
| Delay | 0–9 ходов    | Когда оружие становится доступным |
| Crate | 0–5          | Вес в оружейных ящиках            |

## Опции матча

Время хода, раунда, retreat, rope retreat, hot-seat, победы до выигрыша, стартовое HP,
размещение червяков (случайно/вручную), Worm Select, стокпайлинг (оружие переходит между раундами),
падение (урон вкл/выкл), Artillery mode (нельзя ходить), шансы ящиков (оружие/здоровье/утилиты),
HP в ящике, donor cards, объекты (мины/бочки, количество), фитиль мин и «дуды», Sudden Death
(событие и подъём воды), индестрактибл-земля, супер-оружие в ящиках.

Расширенные (RubberWorm → W:A 3.8): сила и направление гравитации, упругость червяков,
трение, «выстрел не заканчивает ход», множитель урона от падения, поведение верёвки, ветер
и т.д. — около 70 опций.

## Wormpot (WWP)

Слот-машина перед матчем, до 3 модификаторов. Примеры: двойной урон отдельного класса оружия,
скользкая/липкая земля, один «супер-червяк» при ослабленных товарищах, 10 с бесплатной стрельбы,
бессмертные червяки (побеждает только вода), низкая гравитация, ящики каждый ход, «овцы везде».
Главный рычаг реиграбельности без усложнения базовых правил.
